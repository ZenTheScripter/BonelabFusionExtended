**FusionExtended** is a fork of [LabFusion](https://github.com/LavaGang/LabFusion), optimized to provide a smoother, more stable, and feature-rich multiplayer experience for BONELAB.

## 🚀 What is FusionExtended?

The goal of FusionExtended is to take the solid foundation of LabFusion and improve it where it matters most: **performance** and **content**.

This repository aims to provide:
* **Less lag**: Network optimizations in the Proxy for a smoother experience on Quest (Standalone) and PCVR.
* **More gameplay**: Improved compatibility with more mods and game modes.
* **Frequent updates**: Bug fixes and new feature additions.



## 🛠️ Key Features

- **Network Batching**: Grouping data packets to reduce CPU load on standalone devices (Quest).
- **Adaptive TickRate**: Automatic adjustment of the network frequency based on connection quality to prevent stuttering.
- **Extended Mod Support**: Better synchronization of custom objects and entities.

## 📖 Installation

1.  Ensure you have [MelonLoader](https://melonloader.com/) installed.
2.  Download the latest `FusionExtended.dll` from the [Releases](https://github.com/TON_USERNAME/FusionExtended/releases) section.
3.  Place the `.dll` file in your BONELAB `Mods` folder.
4.  Launch the game!
